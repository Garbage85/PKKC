PKKC

Программа для расчёта качественно-количественных и водно-шламовых схем обогащения

PKKC — специализированное настольное приложение для выполнения технологических расчётов схем обогащения полезных ископаемых.

⸻

📋 О программе

Первоначально PKKC была создана Сапожниковым С. Ю. как приложение на Microsoft Access.

Современная версия полностью переработана и представляет собой самостоятельное настольное приложение на Python для Windows.

Для работы не требуется установка Microsoft Access или Python — программа распространяется в виде готового EXE-файла.

⸻

⚙️ Возможности

* Расчёт качественно-количественных схем
* Расчёт водно-шламовых схем
* Работа с технологическими потоками и продуктами обогащения
* Расчёт и контроль балансов схемы
* Сохранение и редактирование выполненных расчётов
* Представление результатов в удобном для анализа виде

⸻

💻 Системные требования

Параметр	Требование
ОС	Windows 7 и новее
Архитектура	x86 / x64
Тип приложения	32-bit (x86)
Python	Не требуется
Microsoft Access	Не требуется

Программа распространяется как единый x86 EXE и работает:

* нативно на 32-битных версиях Windows;
* на 64-битных версиях Windows через WoW64.

Для сохранения совместимости с Windows 7 приложение собирается с использованием Python 3.8 и PyInstaller 5.x.

[!NOTE]
В отдельных системах может потребоваться установка Microsoft Visual C++ Redistributable (x86).

⸻

📦 Установка

1. Перейдите в раздел Releases репозитория.
2. Откройте последний опубликованный релиз.

# PKKC

Программа для расчёта качественно-количественных и водно-шламовых схем обогащения.

Создана Сапожниковым С.Ю. как приложение на Microsoft Access. Текущая версия — настольное приложение на Python: Windows (готовый EXE).

## Системные требования

- **Windows 7 и новее** — и **32-bit (x86)**, и **64-bit**  - Python 3.8 + PyInstaller 5.x (совместимость с Windows 7)
- Один универсальный **x86** EXE (на 64-bit Windows работает через WoW64)
- При необходимости: [Visual C++ Redistributable x86](https://learn.microsoft.com/ru-ru/cpp/windows/latest-supported-vc-redist)
